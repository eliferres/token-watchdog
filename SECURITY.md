# Security policy

## Reporting a problem

Use GitHub's private vulnerability reporting on this repository: the Security tab, then "Report a vulnerability". Do not open a public issue for a security problem.

## What to expect

An acknowledgement within two business days. A confirmed problem gets a fix, a test that pins it and a release, and the report is credited unless you ask otherwise.

## Scope

The code in this repository and the way its command handles the input it is given. Problems in the tools it is run with, or in a project it is pointed at, belong to those projects.

## Supported versions

The newest release only. Older tags get no fixes.
